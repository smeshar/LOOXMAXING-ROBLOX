## Core Loop
1. Заработок денег через базовую механику (TBD).
2. Покупка апгрейдов, увеличивающих доход.
3. Участие в могг-батлах и получение награды за победу.
4. Повышение ранга персонажа.
5. Персонаж должен увеличиваться в процессе прокачки, лицо должно изменяться в труадама.

## Механики
- **Могг-батлы (PvP):** Дуэль двух игроков на скорость кликов. Побеждает тот, кто сделает больше кликов за отведенное время (с учетом критов и предметов). Могг-батлы работают по типу чат-рулеток - когда какие-то игроки нажимают на кнопку, случайных двух закидывает в одно лобби. Даётся время (10 сек) на приготовление. У каждого игрока виден его персонаж и персонаж соперника (свой персонаж слева, персонаж соперника справа, лица персонажей зазумлены). У каждого из игроков написан его PSL (очки, которые будут даваться за клики), ELO, RANK, NAME и т.д.

## Ранги
Ранги видны над головой. Изначальный ранг - `Sub3`
> `Sub3` ➔ `Sub5` ➔ `Ltn` ➔ `Mtn` ➔ `Htn` ➔ `Chad-lite` ➔ `Chad` ➔ `True Adam`
